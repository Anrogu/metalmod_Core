# Metalmod Core
Metalmod Core es una aplicacion de codigo abierto fullstack diseñado para facilitar el registro de reportes de mantenimiento de CNC, Tornos y maquinas dentro de la empresa.

## Stack
- Java ☕
- PSQL 🐘
- SpringBoot 🌿
- Node 🇳
- React ⚛️

## Instalación
 copia el repositorio, genera la base de datos con tus respectivas credenciales y columnas, empieza a usar Metalmod Core.
